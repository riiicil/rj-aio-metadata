### What Was Done
- **Pre-Start Header Select-All Deselection (`src/adapters/DepositphotosAdapter.js`):**

  - Automatically clicks Select All to uncheck it prior to card processing, completely eliminating Depositphotos' default multi-card selection mode that previously caused cross-card edit broadcasts.

  - Refactored `selectCard(cardElement)` to track `this.activeCard` without clicking card checkboxes (`i.itemeditor__selectaction`). This ensures cards are never grouped during individual processing.
- **Sequential Card-Scoped Injection with Namerow Defocus (`src/adapters/DepositphotosAdapter.js`):**
  - Aligned exact sequential workflow:
    1. Clear old description if exists via reset button (`a._itemeditor__reset_description`).
    2. Inject single-string description into `textarea._itemeditor__value_description`.
    3. Defocus description: click `.itemeditor__row.itemeditor__namerow` (or label) and trigger blur to commit value.
    4. Clear old keywords if exists via reset button (`a._itemeditor__reset_keywords`).
    5. Inject keywords: click `span.paste_editor__tag`, inject text into contenteditable `span._tagseditor__tag` (with `InputEvent`, `change`, and `Enter` key simulation), resolving empty keywords box bug.
    6. Defocus keywords: click `.itemeditor__row.itemeditor__namerow` (or label) and trigger blur.
    7. Editorial & Country: conditionally set only when enabled in preferences (`isEditorial: true`), left completely untouched otherwise.
- **Bulk Save Lifecycle Alignment (`src/adapters/DepositphotosAdapter.js`):**
  - Clicks `i.to-top-bicon` (or `window.scrollTo({ top: 0 })`) and waits for scroll to top.
  - Clicks Select All checkbox `i._checkbox.checkbox-bicon.select-all` to select all cards for bulk save.
  - Clicks control panel Save button (`button._cp__action_save`) and polls until the button becomes disabled or sync indicator resolves.
