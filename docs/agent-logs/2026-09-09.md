### What Was Done
- **Strict Element Interaction Sequence on Adobe Stock (`src/adapters/AdobeStockAdapter.js`):**
  - Reordered DOM interaction pipeline inside `fillMetadata()` to strictly follow contributor specifications:
    1. AI Generation & Sanitization
    2. Category Spectrum dropdown (`800ms`)
    3. Generative AI & Fictional Property Release checkboxes (`500ms`, conditional)
    4. Language dropdown (`500ms`)
    5. Title: Clear old title if exists (`200ms`) -> Inject new title (`500ms`)
    6. Keywords: Clear old keywords if exists (`200ms`) -> Inject new keywords (`500ms`)
    7. Done -> Loop next asset.
  - This prevents premature title/keyword clearing before category and language are committed, ensuring Adobe Stock's tagger does not trigger auto-category recomputation.
- **Graceful Stop with Active Card Completion and Bulk Save (`src/overlay/overlay.js`):**
  - Upgraded `startAutomation()` and `stopAutomation()` to implement professional microstock graceful shutdown:
    - If user clicks "Stop Automation" while a card is actively being processed (`this.isCardProcessing === true`), the system enters `this.isStopping = true` state.
    - The active in-flight card is allowed to complete its metadata injection cleanly (no half-filled cards).
    - Upon finishing the active card, the asset loop breaks out and triggers `adapter.bulkSave()`:
      - Clicks "Select all" (or checkbox icon).
      - Checks releases switch if needed.
      - Clicks "Save work" button.
    - If user clicks Stop during cooldown delay, the delay is interrupted immediately to trigger bulk save without idle waiting.
    - If user clicks Stop a second time while in "Stopping..." state, immediate hard abort is performed via `AbortController`.
    - `this.isAutomationRunning` is properly transitioned so the UI indicates stopping status and synchronous HUD controls remain responsive.
- **Reasoning Model Token Quota Upgrade (`src/services/AiPrompt.js`):**
  - Increased `effectiveMaxTokens` for reasoning models (`o1`, `o3`, `o4`, `gpt-5`) from `8192` to `16384`.
  - Empirically verified via live API diagnostics that OpenAI reasoning models consume >2100 completion tokens strictly for thinking/reasoning before generating JSON content; 16K tokens eliminates `TOKEN_LIMIT_EXCEEDED` errors on high-resolution image inputs.

## Session Entry 1 — Adobe Stock Card Deduplication, Reasoning Model Headroom, Sequential Timing & Styled Console Logging

### What Was Done
- **Asset Card Deduplication (`src/adapters/AdobeStockAdapter.js`):**
  - Resolved the critical bug where Adobe Stock detected 70 asset cards for 35 assets (`asset 1/70`).
  - Root cause: `getAssetCards()` queried both `div.content-grid-elements` and descendant `div.upload-tile`, matching both parent and child elements. Card 1 was processed in iteration 0, then its child tile was re-processed in iteration 1, producing an off-by-one desynchronization across all subsequent cards.
  - Fixed by querying `div.content-grid[data-t="assets-content-grid"] div.content-grid-elements` and strictly filtering out any nested descendant tiles.
- **Card Selection Confirmation Polling (`src/adapters/AdobeStockAdapter.js`):**
  - Upgraded `selectCard` to poll up to 6 times (~1200ms) inspecting `aria-selected === 'true'` on `.upload-tile [role="option"]`.
  - Added a retry click if the first attempt didn't take, followed by a 200ms settling delay.
  - Eliminated redundant secondary container clicks that previously cancelled or toggled selections.
- **AI Reasoning Token Quota Headroom (`src/services/AiPrompt.js` & `src/services/AiService.js`):**
  - Resolved `Model token limit exceeded before completion (finish_reason: length)` on reasoning models (`gpt-5-nano`, `o1`, `o3`, `o4`).
  - Increased default `max_completion_tokens` from 1200 to `8192` for reasoning and GPT-5 models (and `4096` for standard models), giving ample headroom for internal reasoning/thinking tokens while reliably generating complete JSON metadata.

- **Auto-Category Refresh Removal (`src/adapters/AdobeStockAdapter.js`):**
