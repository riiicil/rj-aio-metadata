### What Was Done
- **Asset Card Deduplication (`src/adapters/AdobeStockAdapter.js`):**
  - Resolved the critical bug where Adobe Stock detected 70 asset cards for 35 assets (`asset 1/70`).
  - Root cause: `getAssetCards()` queried both `div.content-grid-elements` and descendant `div.upload-tile`, matching both parent and child elements. Card 1 was processed in iteration 0, then its child tile was re-processed in iteration 1, producing an off-by-one desynchronization across all subsequent cards.
  - Fixed by querying `div.content-grid[data-t="assets-content-grid"] div.content-grid-elements` and strictly filtering out any nested descendant tiles.
- **Card Selection Confirmation Polling (`src/adapters/AdobeStockAdapter.js`):**
  - Upgraded `selectCard` to poll up to 6 times (~1200ms) inspecting `aria-selected === 'true'` on `.upload-tile [role="option"]`.
  - Added a retry click if the first attempt didn't take, followed by a 200ms settling delay.
  - Eliminated redundant secondary container clicks that previously cancelled or toggled selections.
- **AI Reasoning Token Quota Headroom (`src/services/AiPrompt.js` & `src/services/AiService.js`):**
  - Resolved `Model token limit exceeded before completion (finish_reason: length)` on reasoning models (`gpt-5-nano`, `o1`, `o3`, `o4`).
  - Increased default `max_completion_tokens` from 1200 to `8192` for reasoning and GPT-5 models (and `4096` for standard models), giving ample headroom for internal reasoning/thinking tokens while reliably generating complete JSON metadata.
  - Added optional `maxTokens` parameter pass-through in `AiService.generateMetadata`.
- **Auto-Category Refresh Removal (`src/adapters/AdobeStockAdapter.js`):**
  - Completely removed the fallback click on `button[data-t="refresh-auto-category"]` that was triggering Adobe Stock's notice *"The auto-category has been regenerated."*.
- **Strict Sequential Element Execution & Millisecond Delays (`src/adapters/AdobeStockAdapter.js` & `src/overlay/overlay.js`):**
  - Restructured `fillMetadata` into a discrete, sequential pipeline with millisecond pauses between each element to avoid race conditions:
    - Card selection confirmed -> `sleep(600ms)`
    - Editor ready confirmed -> `sleep(300ms)`
    - Thumbnail extraction & AI request -> `sleep(500ms)`
    - Clear old metadata -> `sleep(300ms)`
    - Set language dropdown -> `sleep(500ms)`
    - Set category Spectrum dropdown -> `sleep(800ms)`
    - Clear & set title input -> `sleep(500ms)`
    - Clear & set keywords textarea -> `sleep(500ms)`
    - Set Generative AI & property release checkboxes -> `sleep(500ms)`
    - Post-loop bulk save: Select All -> `sleep(1000ms)` -> Releases switch to 'no' -> `sleep(500ms)` -> Save work button -> `sleep(1000ms)`.
- **Structured Console Logging System (`src/services/AiService.js`, `src/adapters/AdobeStockAdapter.js`, `src/overlay/overlay.js`, `src/background/service_worker.js`):**
  - Implemented informative, styled browser DevTools console logging with prefix `[RJ AIO Metadata]`:
    - Loop progression: `[RJ AIO Metadata] --- Processing asset 1 of 35 ---`
    - AI requests: `[RJ AIO Metadata] Requesting AI metadata for asset 1 to OpenAI (gpt-5-nano)...`
    - Raw AI output and sanitized metadata logging.
    - Form element operations: `Setting category: ...`, `Setting title: ...`, `Setting keywords: ...`, `Setting Generative AI: ...`
    - Background API error logging and parameter self-healing notifications.
