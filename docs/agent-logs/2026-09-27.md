### What Was Done
- **Popup vs HUD State Synchronization Guard (`src/popup/popup.js`)**:
  - Scoped the `isSavingLocally` guard in `chrome.storage.onChanged` strictly to settings and provider configuration updates (`platformSettings`, `providers`, `activeProvider`, `activePlatform`).
  - Previously, placing `if (isSavingLocally) return;` at the root of `chrome.storage.onChanged` caused incoming automation state signals (`changes.rj_automation_state`) and HUD visibility toggles (`changes.rj_overlay_visible`) to be dropped whenever local popup inputs were being auto-saved.

  - Added `isCurrentTabMatched()` helper and integrated it into the idle evaluation branch of `updateAutomationButtonUI()`.
  - The Start button is now disabled with title `"Active tab does not match this platform"` whenever the active tab URL does not correspond to the selected platform.
  - Added click guard in `btnToggleAutomation` click listener blocking execution if the tab is not matched.
  - Dynamically refreshes button readiness upon active tab query completion (`GET_ACTIVE_TAB_INFO`) and platform dropdown changes (`platformSelect.addEventListener('change')`).
- **Depositphotos Non-English Locale URL Detection Fix (`src/adapters/DepositphotosAdapter.js`)**:
  - Updated `isMatch(url)` in `DepositphotosAdapter.js` to check `url.includes('depositphotos.com') && url.includes('/files/unfinished')`.
