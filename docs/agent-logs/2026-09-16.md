### What Was Done
- **Locked Button Contrast Hardening (`src/overlay/overlay.css`, `src/styles/components.css`)**:
  - Resolved unreadable dark button bug on locked HUD action buttons: `.rj-hud-btn-action` originally lacked a fallback surface color when `.rj-btn-start` was detached, causing the button to inherit the black canvas (`#07080a`) while `:disabled` washed it out with `opacity: 0.45`.
  - Added `.rj-hud-btn-action.rj-btn-locked` and `.rj-btn.rj-btn-locked` CSS classes with Raycast Dark elevated surface (`background-color: #141719 !important`), hairline border (`border: 1px solid #282b2e !important`), light silver-gray text (`color: #c0c4c7 !important`), crisp visibility (`opacity: 0.95 !important`), and muted lock icon stroke (`stroke: #8a9096 !important`).

- **Popup Concurrency Lock Synchronization (`src/popup/popup.js`)**:
  - Diagnosed root cause of popup button showing red `Stop Automation` when viewing a non-runner platform:
    1. `currentActivePlatformId` initialized as `null`, causing `isDifferentPlatform` to evaluate to `false` during synchronous initial execution.
    2. Asynchronous `GET_ACTIVE_TAB_INFO` previously updated `currentActivePlatformId` without re-evaluating `updateAutomationButtonUI`.
    3. `updateAutomationButtonUI` was called with a bare boolean `isAutomationRunning`, discarding `runnerPlatformId` context.
  - Implemented `lastAutomationState` module-level state persistence: preserves runner metadata even across boolean UI sync updates.
  - Dynamic platform targeting: `isDifferentPlatform` now inspects `platformSelect?.value || currentActivePlatformId`, ensuring the locked state reflects whichever platform form is selected in the UI.
  - In `DOMContentLoaded`: awaited `GET_ACTIVE_TAB_INFO` tab platform detection before restoring `rj_automation_state` and updated `updateAutomationButtonUI(lastAutomationState || isAutomationRunning)`.
  - In `platformSelect` change listener: re-evaluates `updateAutomationButtonUI(lastAutomationState)` to dynamically reflect the runner lock in real time.
  - Added click guard in `btnToggleAutomation` ignoring events if `.rj-btn-locked` is present.
