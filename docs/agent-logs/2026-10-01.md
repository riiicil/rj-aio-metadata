### What Was Done
- **Investigated Multi-Platform Opening Tug-of-War & Browser Freeze ("Not Responding")**:
  - Investigated issue reported where opening multiple platforms simultaneously caused browser freezes ("Not Responding") and CPU 100% lockups.
  - Identified 4 interconnected root causes:
    1. **Unawaited Tab ID (`overlay.js:init`)**: `chrome.runtime.sendMessage({ action: 'GET_SENDER_TAB_ID' })` was fired without awaiting, leaving `this.tabId` as `null` when `restoreAutomationState()` evaluated on mount.
    2. **Same-Platform Storage Contention (`overlay.js:onStorageChanged`)**: Storage listener checked `state.platformId !== this.platformId` but failed to check `state.tabId !== this.tabId`. When two tabs of the same platform were open (or `state.platformId` was empty), Tab 2 received `isRunning: true` and called `this.startAutomation()`. If Tab 2 had 0 cards, it immediately broadcast `isRunning: false`, causing Tab 1 to abort and triggering an infinite IPC ping-pong loop at 60fps that locked Chromium's main process.
    3. **Sibling Tab Mount Wiping Storage (`overlay.js:restoreAutomationState`)**: In `restoreAutomationState()`, freshly loaded tabs ran `if (isStopping || (isRunning && !this.orchestrator?.isProcessing))` and reset `rj_automation_state` to `isRunning: false`, abruptly terminating active batches running on sibling tabs.
    4. **Unthrottled Mutation Observer during Page Loads (`overlay.js:startAssetScanner`)**: Multiple tabs simultaneously observing `document.body` with `{ childList: true, subtree: true }` and running DOM card scans on background tabs saturated CPU threads.
- **Implemented Comprehensive Tab Isolation & Performance Throttling**:
  - **Promisified Tab ID Resolution (`src/overlay/overlay.js`)**: Wrapped `GET_SENDER_TAB_ID` in a Promise and awaited it in `init()`, guaranteeing `this.tabId` is a valid integer prior to state restoration.
  - **Strict Tab Scoping in Storage Listener (`src/overlay/overlay.js`)**: Added `isAnotherTab = Boolean(state.tabId && this.tabId && state.tabId !== this.tabId)`. If either `isAnotherPlatform` OR `isAnotherTab` is true, the HUD immediately sets the `Busy` lock (`Busy (another tab)` or `Busy (another platform)`) and returns without invoking `startAutomation()` or `stopAutomation()`.
  - **Sibling Mount Isolation (`src/overlay/overlay.js`)**: In `restoreAutomationState()`, added early return locking the HUD if another tab/platform is currently running, and scoped auto-heal to only reset state if `isMyTabState` (`!state.tabId || !this.tabId || state.tabId === this.tabId`).
  - **Popup Tab ID Association (`src/popup/popup.js`)**: In `btnToggleAutomation` handler, populated `tabId: activeTabInfo?.tabId || null` into `rj_automation_state`.
  - **Background Tab Scanner Throttling (`src/overlay/overlay.js`)**: In `startAssetScanner()`, added `document.hidden` guards skipping scans when tabs are in the background, and raised observer debounce from 300ms to 500ms.
