- **Evaluated Obfuscation Architecture vs Previous Microstock Projects**:
  - Analyzed `RJ_AdobeStock_Auto` and `RJ_Shutterstock_Auto` build setups (`build.js`, `obfuscator.config.js`).
  - Evaluated architectural risks: Identified that naive file-by-file obfuscation on modern ES Modules breaks inter-module import bindings (`SyntaxError: The requested module does not provide an export`).
  - Selected Option 2 (Bundle-First + Obfuscate): Uses `esbuild` to cleanly resolve and bundle all internal ESM dependencies into self-contained files (`background/service_worker.js`, `popup/popup.js`, `overlay/overlay.js`, `content/content_main.js`), followed by `javascript-obfuscator` for deep AST control flow flattening and string encryption.
- **Crafted Manifest V3 Tailored Obfuscator Config (`obfuscator.config.js`)**:
  - `disableConsoleOutput: false`: Strictly preserves developer logs, `logger.step()`, and console outputs.
  - `debugProtection: false`: Prevents browser lockups / infinite debugger loops when DevTools is opened.
  - `renameGlobals: false`: Guarantees Chrome Extension APIs (`chrome.*`, `document.*`, `window.*`) are untouched.
  - `selfDefending: false`: Ensures background service worker execution context stability.
  - `stringArrayEncoding: ['base64']`: Safely encodes strings, prompts, and DOM selectors.
- **Implemented Automated Build & Packaging Pipeline (`build.js`, `package.json`)**:
  - Cleans and prepares `dist/` and `releases/`.
  - Bundles the 4 MV3 entry points via `esbuild` in 19ms.

  - Copies static assets (`manifest.json`, `popup.html`, `popup.css`, `overlay.css`, `styles/`, `icons/`).
  - Automatically cleans `web_accessible_resources` in `dist/manifest.json` to reflect bundled assets.
  - Packages `dist/` into a release zip: `releases/v[version].zip` (1.21 MB).
