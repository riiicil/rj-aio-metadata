### What Was Done
- **Prompt Engine Core Implementation (`src/services/AiPrompt.js`):**
  - Implemented `PLATFORM_CATEGORIES` dictionary extracting official microstock taxonomies:
    - Adobe Stock: 21 official categories with numeric IDs (`10001` Animals to `10988` Travel).
    - Shutterstock: 26 Image categories vs 19 Video categories (strictly omitting abstract, beauty, interiors, vintage, etc. on video).
    - Dreamstime: Complete 15 Main categories and hierarchical subcategory trees from technical reference analyses.
    - Depositphotos, Vecteezy, Freepik, MiriCanvas: Defined as empty objects (no category selection needed).
  - Implemented `getPlatformOutputSchema(platformId, options)` returning platform-customized JSON schemas:
    - Adobe Stock: `title`, `category`, `keywords`.
    - Shutterstock: `description`, `category_1`, `category_2`, `keywords`.
    - Dreamstime: `title`, `description`, `categories` (dynamically requesting 3 pairs for standard or 2 pairs for AI-generated assets), `keywords`.
    - Depositphotos, Vecteezy, Freepik, MiriCanvas: Strict schemas with category fields completely omitted.
  - Implemented `buildPrompt({ platformId, assetType, language, isAiGenerated })`:
    - System prompt establishing world-class microstock contributor SEO specialist persona.
    - Flat 80-keyword quota ordered strictly by relevance (specific primary subject to broader contextual terms).
    - Keyword structure constraint: 1-2 words max, no punctuation, symbols, or sentence fragments.
    - Forbidden spam terms avoidance (`FORBIDDEN_KEYWORDS`: `best`, `top`, `isolated`, `white background`, `no people`, `copy space`, trademarks).
    - Adobe Stock target language support (`ADOBE_LANGUAGES`) specifying non-English language instructions when configured.
    - Shutterstock distinct dual-category selection instruction.
  - Implemented `buildChatPayload({ model, systemPrompt, userInstruction, imageBase64, temperature, maxTokens })`:
    - Constructed OpenAI-compatible `POST /v1/chat/completions` request body with `response_format: { type: "json_object" }` and `max_completion_tokens: 1200`.
    - Implemented `normalizeBase64Image(base64Str)` to strip data URI prefixes and format clean `data:image/jpeg;base64,...` with `detail: "low"` to save >90% tokens.
    - Implemented critical model parameter safety guard `/^(o1|o3|gpt-5)/i.test(model)`: automatically omits the `temperature` parameter for GPT-5 and reasoning models to avoid HTTP 400 rejection errors, while preserving `temperature: 0.7` for Gemini, Mistral, and GPT-4o.
